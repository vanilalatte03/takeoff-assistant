## 도면 출처

도면은 이 프로젝트의 공개 시연을 위해 새로 작성한 가상 사무실입니다. 실제 건물, 고객, 주소, 외부 도면을 포함하지 않습니다. 시공이나 실제 견적에 사용할 수 없습니다. PDF에는 필요한 글자의 폰트 서브셋이 포함되며 별도 폰트 파일은 배포하지 않습니다.

README용 PDF는 공개 시연을 위해 작성한 가상 도면입니다. 로컬 생성·촬영 작업 폴더는 공개 소스에 포함하지 않습니다. 공개용 자료에는 원본 업무 PDF, 개인용 dataset, 시연 데이터베이스와 Excel 출력물을 포함하지 않았습니다.

## 재현 순서

1. [실행 명령](../COMMANDS.md)에 따라 API와 웹 앱을 실행합니다.
2. PDF Upload에서 프로젝트를 만들고 위 가상 도면 PDF를 업로드합니다. 화면에 표시되는 Drawing File ID를 사용합니다.
3. `Process pages`, `Detect sheets`, `Classify sheets`를 순서대로 실행합니다.
4. 도면 목록에서 검색하면 평면도 `A110`, 마감표 `A710`, 가벽·개구부 상세 `A330`이 나옵니다. 이 번호는 예시 파일의 번호이며 앱의 고정 규칙이 아닙니다.
5. Room Finish에서 Drawing File ID를 입력하고 `Extract`를 실행합니다. 101~105의 5개 실과 `NEEDS_REVIEW` 상태를 확인합니다.
6. Measurement에서 같은 ID를 입력하고 `Generate`를 실행합니다. 실별 4개 공종, 총 20개 후보가 생성됩니다.
7. 101실의 `FLOOR / LVT-01` 후보를 선택합니다. 사각형 면적의 Width에 `4.20`, Height에 `3.60`, Source Sheets에 `A110, A710`을 입력합니다.
8. `4.2 * 3.6 = 15.12 m2`를 확인하고 `계산 저장`을 누릅니다. 이 시연에서는 확정 체크를 선택하지 않아 `DRAFT`를 유지합니다.
9. `Export Excel`로 내려받고 `Summary`, `Details`, `Review` 시트를 확인합니다.

도면의 치수는 mm이고 계산 입력은 m입니다. 마감표의 `HGT 2700`은 천장 높이입니다. 104실 벽 타일의 별도 높이 1200 mm와 문·개구부 공제 등은 도면 주석을 읽고 별도로 반영해야 합니다. 이 시연은 치수 직접 입력을 사용하며 자동 치수 선택이나 도면 위 측정 좌표 저장을 보여주지 않습니다.

## 확인한 범위

- 실제 브라우저에서 PDF 업로드 → 3개 페이지 처리·분류 → 5개 실 추출 → 20개 후보 생성 → 101실 바닥 계산 저장 → Excel 다운로드를 실행했습니다.
- 내려받은 Excel의 3개 시트와 Details의 `101 / FLOOR / LVT-01`, 계산식 `4.2 * 3.6`, 수량 `15.12`, 단위 `m2`, 출처 `A110, A710`, 상태 `DRAFT`를 확인했습니다.
- 계산하지 않은 나머지 19개 후보의 수량은 비어 있습니다. 전체 수량 자동 산출, 공제 검증, 실제 업무 도면 정확도나 모든 사용자 흐름을 검증한 자료는 아닙니다.

README는 저장소 안의 상대 경로로 PNG·GIF를 표시하고 MP4·PDF를 연결합니다. MP4는 다운로드 링크이며, GitHub에 직접 업로드한 첨부 영상은 아닙니다.

## 최신 main과의 대조

촬영 당시 화면은 2026-11-04 로컬 앱 기준입니다. 공개 준비 과정에서 최신 main의 실제 API·SQLite·PDF·Excel 처리로 같은 3장 도면을 다시 실행해 5개 실, 20개 후보, 101실 바닥 15.12 m2와 DRAFT 상태, A710·A110 출처를 확인했습니다. 출처의 표시 순서는 병합 규칙에 따라 달라질 수 있습니다. 기존 영상은 이후 UI 변경을 모두 반영한 촬영본이라는 뜻은 아닙니다.

같은 공개 준비 브랜치에서 Chromium으로 새 프로젝트 생성 → PDF 업로드 → 3페이지 처리·분류 → 마감 5개 실 추출 → 후보 20개 생성 → 101실 바닥 계산 저장 → Excel 다운로드도 실행했습니다. 다운로드한 workbook에서 15.12 m2, DRAFT, A710·A110 출처, 세 시트와 나머지 19개 항목의 빈 수량을 확인했습니다. 자동 치수 선택·수동 좌표 측정·공제 전체를 검증한 것은 아닙니다.
