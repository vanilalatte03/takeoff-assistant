# PRD: Takeoff Assistant

## 제품 방향

Takeoff Assistant는 PDF 건축 도면에서 마감 산출표를 만드는 과정을 보조하는 개인용 검수 도구입니다.

제품의 핵심 방향은 "PDF를 넣으면 완성 엑셀"이 아닙니다. 시스템이 산출 초안을 만들고, 사용자가 빠르게 검수/수정/확정한 뒤 추적 가능한 Excel 결과를 내보내는 흐름입니다.

## 해결할 문제

현재 수동 산출 과정은 다음 작업이 반복됩니다.

- PDF 페이지를 오가며 도면 번호와 도면명을 확인
- Room No와 finish schedule을 대조
- 평면도에서 치수를 찾아 계산
- 공제, 양면 산출, 예외 규칙을 수기로 반영
- 계산식과 도면 출처를 Excel에 다시 입력

이 프로젝트는 자동화보다 **검수 속도와 출처 추적성**을 우선합니다.

## 사용자

- Primary: PDF 도면과 Excel로 건축 마감 산출을 수행하는 단일 개인 사용자
- Secondary: 현재 범위에는 없음

## 제품 원칙

- 자동 추출 결과는 확정값이 아니라 검수 대상입니다.
- 틀린 추출을 빨리 고치는 UI가 추출 정확도보다 중요합니다.
- 모든 수량은 formula, status, source sheet를 유지해야 합니다.
- 도면 번호 하드코딩에 의존하지 않고 도면명/역할 기반으로 찾습니다.
- 계산 엔진은 사람이 이해할 수 있는 식을 보존합니다.

## 단계별 방향

### 1차: 기능 동작 MVP

PDF 업로드부터 Excel export까지 기본 흐름이 동작해야 합니다.

- PDF 업로드, page count, 페이지 렌더링, 텍스트 추출
- 도면 번호/도면명/역할 감지
- 도면 검색
- 마감표 페이지 탐지
- RoomFinish 후보 추출
- Measurement 후보 생성
- 치수 직접 입력과 계산 엔진
- Summary/Details Excel export

### 2차: 실제 업무 검수형 MVP

아버님이 실제 샘플 도면으로 써볼 수 있게 검수 UI를 다듬습니다.

- RoomFinish 테이블 수정 속도 개선
- Measurement 후보 삭제/병합/수정
- NEEDS_REVIEW / CONFIRMED 상태 흐름 강화
- 방별 계산 상태 표시
- Excel 결과를 실제 사용 양식에 가깝게 조정

### 3차: 도면 위 치수 선택 보조

자동 치수선 판독이 아니라 사용자가 선택한 방 주변 치수 후보를 추천하는 반자동 흐름을 목표로 합니다.

- Room No 검색 후 관련 페이지 이동
- 사용자가 방 영역 드래그
- 주변 숫자 치수 후보 표시
- 사용자가 가로/세로 후보 선택
- 선택값으로 면적/둘레 계산

### 4차: 산출 예시 데이터셋 확장

자동화 품질을 높이기 위해 실제 산출 예시를 축적합니다.

- 실제 산출 행 20~50개 수집
- 각 행의 참고 도면, 가져온 치수, 계산식, 공제 여부 기록
- 방별/마감코드별 예외 규칙 정리

### 5차: AI 보조 자동화

AI는 계산을 대체하지 않고 후보 탐색과 근거 설명을 보조합니다.

- 특정 마감 코드가 들어간 방 후보 찾기
- Room 위치 후보 찾기
- Finish schedule row 추출 보정
- 누락 가능성이 있는 후보 표시
- 선택한 산출 행의 근거 설명 생성

## 제외 방향

다음은 단기 제품 방향이 아닙니다.

- 완전 자동 견적 생성
- 검수 없는 자동 확정
- 스캔 PDF 전체 OCR 파이프라인
- 다중 사용자 권한
- cloud deployment
- XCost import/export

## 성공 기준

- 사용자가 PDF 업로드부터 Excel export까지 중단 없이 진행할 수 있습니다.
- 틀린 추출 결과를 직접 수정할 수 있습니다.
- 계산식, 수량, 단위, 상태, 도면 출처가 함께 남습니다.
- 실제 샘플 도면 기준으로 수동 산출보다 빠르게 검수 가능한 초안을 만듭니다.
