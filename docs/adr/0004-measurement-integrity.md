# ADR-004: 산출 소속과 계산 근거의 일관성

상태: accepted

## 맥락

검수·수동 측정·계산·병합은 같은 Measurement를 갱신한다. 기존 구현은 경로마다 상태와 출처를 다르게 처리하여 중복 합계, 공제 소실, PDF 간 데이터 혼합이 발생했다.

## 결정

- 수동 RoomFinish의 PDF 소속을 명시적으로 보존한다. 기존 SQLite에는 컬럼을 추가하고 명확한 sheet 소속만 채운다. 불명확한 옛 행은 추정 배정하지 않는다.
- 일반 산출 타입의 단위·치수와 검수 상태 변경은 API 경계에서 공통 검증한다. 확정 해제는 별도의 명시적 사용자 행동이며 거절 행의 암묵적 복구를 허용하지 않는다.
- 재계산 입력은 서버가 `coordinates_json.calculation_inputs`에 JSON으로 보존한다. 기존 geometry/dimension assist JSON과 공제 계약을 유지한다.
- 새 수동 측정은 옛 계산 입력·공제를 무효화하고 기존 메모·치수 선택 근거·출처를 보존한다. 병합은 원본 근거를 함께 남기며 거절 원본을 최종 합계에서 제외한다.

## 결과

DB 전체 재생성이나 다중 사용자 구조 도입 없이 기존 local-first 방식을 유지한다. 미배정 legacy 행은 손실 없이 남지만 파일별 산출에는 자동 포함하지 않는다. 백엔드 통합 회귀와 프론트엔드 컴포넌트 회귀를 함께 실행한다. 세부 동작은 `docs/INTEGRITY_FIXES.md`를 따른다.
