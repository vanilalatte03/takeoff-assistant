# 산출 보조와 원본 대조 화면

산출 탐색 보조에서 프로젝트/PDF와 로컬·AI 방식을 선택하고 실 번호·마감 코드를 검색한다. 근거 페이지를 확인한 뒤 산출 행을 고르고 치수별 출처·단위·메모, 공제 여부, 파티션 면 수를 확인해 DRAFT로 저장한다. AI 모드는 요청 문장이 외부 전송됨을 표시한다.

도면 상세의 Dimension region에서 텍스트 추출 실패 영역을 선택하면 로컬 미리보기를 볼 수 있다. 실패 유형·메모·전송 권한을 확인한 뒤 해당 영역만 판독한다. 후보와 단위를 사용자가 검수한 후 계산 초안에 사용한다.

초안 저장 직후와 산출 수정 폼에서 원문 값·확인 단위·실제 계산 입력·현재 결과·출처 이미지를 나란히 확인한다. 현재 결과나 원본이 달라졌으면 경고한다. 기록 없는 과거 행의 치수를 추정해 채우지 않는다. 확정 행에서도 읽기 전용 대조를 사용할 수 있다.

실사용 비교 패널은 사용자가 측정한 전체 작업시간과 수정·개입·오류·채택 여부를 기록한다. 자동 정확도나 실무 성과를 뜻하지 않는다.
