# 작업 도면 선택

업로드·도면 목록·마감 검수·산출 화면은 프로젝트와 PDF 이름으로 파일을 선택한다. `GET /projects/{id}/drawing-files`는 해당 프로젝트 파일만 반환한다.

선택은 URL drawingFileId와 탭의 sessionStorage에 유지된다. 같은 화면의 주소·뒤로/앞으로 이동에도 선택과 프로젝트가 동기화된다. PDF가 바뀌면 화면을 다시 만들어 이전 PDF의 결과·미저장 입력을 초기화한다. 실제 산출 데이터는 변경하지 않는다.

프로젝트 API 범위, 같은 경로 URL 변경, 브라우저 이력, 기존 마감 확정/제외 동작을 회귀로 확인한다.
