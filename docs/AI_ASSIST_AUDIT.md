# AI 보조 PRD 요구사항 감사

기준 문서는 [AI_ASSIST_PRD.md](AI_ASSIST_PRD.md)의 v0.1 요구사항이다. 기능 구현, 합성 검증, 실제 도면 동작 확인, 실모델·실무 검증을 구분한다. 테스트 통과만으로 전체 PRD 완료를 선언하지 않는다.

## 진행률을 세는 기준 (2026-11-05)

12개 요구사항을 같은 비중으로 보고, 구현과 해당 수용 기준의 개발자 검증을 갖춘 항목을 1개로 센다. R-01/02/03/05/06/07/08/09/10의 9개는 이 수준을 확인했다. R-04/11/12는 기반은 있으나 검수된 정답 데이터·실제 도면 판독 평가·실사용 비교가 남아 있어 부분 진행으로 남긴다.

따라서 약 75%(9/12)는 **요구사항 개수에 따른 간이 진척 지표**다. 남은 공수의 비율·실무 정확도·출시 승인 비율을 뜻하지 않는다. 현장 검증 없는 부분을 구현된 화면이나 테스트 개수로 대신 완료 처리하지 않는다.

## 불변 조건과 경계

- 도면 번호를 제품 규칙으로 고정하지 않는다. 검색은 역할·제목·텍스트 근거로 순서를 정한다.
- 모델에는 파일/프로젝트 선택, 로컬 경로, 임의 수량·계산식 저장, CONFIRMED 도구가 없다.
- 치수 누락·단위 미확인·근거 혼합·과다 공제·과거 원본은 저장을 막는다. 선택 영역 이미지가 바뀌면 재판독해야 한다.
- 모델 장애 또는 설정 누락은 FAILED로 표시하며 수동 흐름을 유지한다. 근거 없음은 NOT_FOUND다.
- Excel Summary/Review는 REJECTED 수량을 제외하고 Details는 상태와 함께 이력을 보존한다.
- 실제 PDF·XLSX·추출된 업무 행·사설 검증 이미지를 공개 문서나 Git에 추가하지 않는다. 로컬 smoke의 DB·렌더·결과는 임시 폴더에 분리했다.
- cloud/multi-user/외부 견적 시스템/멀티 에이전트 플랫폼은 추가하지 않았다.

## 완료를 막는 외부 조건

사용자가 제공한 외부 설정으로 실제 검색·합성 이미지 판독을 수행했고, 합성 E-01~E-06/V-01~V-03 최신 9항목이 통과했다. 외부 설정을 읽은 서버의 두 기능 사용 가능 여부도 true로 확인했다. 키 설정에 따른 차단은 해소됐다. 구체적 범위·사용량·반복 실행 한계는 AI_ASSIST_PROGRESS.md와 AI_ASSIST_LIVE_RESULT.json을 따른다.

남은 작업은 실무자가 원본과 산출표를 검수하고 비교 과제를 수행하는 것이다. 2026-11-05 당시에는 정답 산출표와 실제 도면의 외부 전송 가능 여부가 확인되지 않았다. 아래 최신 상태를 함께 확인하며 실제 정확도·시간 단축·전체 PRD 완료를 주장하지 않는다.

## 후속 개발 상태 (2026-11-06)

[사용성·평가 phase](../phases/6-usability-evaluation/README.md)에서 검수 데이터, 검색 기준선, 작업 흐름, Windows 실행, Vision 실패 평가와 파일럿을 PR 단위로 진행한다. 이 계획 추가는 R-04/11/12의 완료 증거가 아니다. 2026-11-05의 호출·테스트 기록은 당시 관찰값으로 유지하며 이 문서 수정에서 재실행했다고 주장하지 않는다.

## 최신 확인과 남은 게이트 (2026-11-09)

6차 단계 0~6은 개발 검증을 완료했다. 검수 기록 로더·고정 합성 검색 평가·업로드부터 Excel까지의 작업 안내·Windows 클릭 실행·합성 Vision 실패 평가·세 방식 파일럿 기록/분석을 준비했다. 구체적인 지표와 범위는 각 phase 단계와 [FIELD_PILOT](FIELD_PILOT.md)을 따른다. 실제 파일럿 관찰은 0건이며 이 개발 완료로 R-04/11/12를 완료 처리하지 않는다.

사용자는 앱에 설정한 OpenAI Responses API를 통한 선택 영역 PNG 전송 범위를 허용했다. Codex 앱 모델 설정과 앱 서버의 외부 `.env` 설정은 별개다. 도면별 이용권한·미리보기·전송 consent 확인은 유지한다. 5종 합성 이미지의 실모델 단일 실행은 [Vision 평가](VISION_FAILURE_EVALUATION.md)에 별도 기록돼 있으며 실제 업무 판독 품질·전체 시간 절감 증거가 아니다.

실무자 참여 일정은 미정이다. 실무자가 승인한 정답 20~50건과 실제 작업 관찰·비교가 없어 단계 7은 blocked다. 클릭 실행기에는 검색 모델만 설정된 경우 이미지 지원 모델을 판독에도 재사용하는 명시 옵션을 보완했으며, 기본 꺼짐·별도 판독 모델 우선·프로세스 내 적용 원칙은 [Windows 안내](WINDOWS_LAUNCH.md)를 따른다.
