# 치수 입력과 산출 후보 보정

명시 단위가 붙은 `2.7m`와 `80mm`를 숫자의 일부만 읽거나 크기로 재추정하지 않고 해당 단위로 정규화한다. 실무 단위 확인과 최종 확정은 사용자 검수로 남긴다.

사용자가 마감 코드를 수정한 뒤 후보를 재생성해도 같은 마감 행·산출 유형의 후보를 중복 생성하지 않는다. 제외된 마감 행·확정 산출 보호와 Excel 텍스트 셀 보안은 기존 main 계약을 유지한다.

합성 PDF 두 사례의 업로드→추출→계산→확정 보호→Excel 식/수량/단위/출처를 검증한다. 실제 업무 정답 승인을 뜻하지 않는다.
