# 산출 보조 기능 사용 안내

이 앱은 도면에서 관련 페이지와 치수 후보를 찾고, 사용자가 확인한 입력으로 계산 초안을 만드는 도구다. 최종 수량을 자동 확정하지 않는다.

## 사용 흐름

1. 기본 **작업 시작·이어서 하기** 화면에서 PDF를 선택한다. 처음이면 **새 PDF 업로드**에서 프로젝트를 선택하거나 만들고 PDF를 올린다.
2. **도면 준비 시작·이어서 진행**을 누르면 페이지 처리·감지·분류·마감 추출·산출 후보 생성이 차례로 이어진다. 실패하면 같은 버튼으로 남은 단계부터 재시도한다. 후보가 없으면 화면에 표시된 분류 확인·수동 입력 경로를 이용한다.
3. 같은 화면에서 `110호 ACST 천장`처럼 찾을 항목을 입력한다. 검색 근거를 펼쳐 원본을 확인하고 산출 행을 선택한다.
4. 치수별 출처 페이지와 후보 또는 수동값을 선택하고, 확인 단위·검수 메모를 입력한다. 공제·면 수를 확인하고 미확정 초안을 저장한다.
5. **아래 원본 검토·Excel로 이동**으로 저장값과 원본을 대조한다. 저장된 행은 이 화면을 다시 열어 재개할 수 있다. 수동 수정과 명시적 최종 확정도 접힌 계산 폼에서 할 수 있다.
6. 검토 체크 후 **Excel 다운로드**를 누른다. Summary/Details/Review에서 결과와 남은 검수 상태를 확인한다. 자세한 [재개·실패·데이터 보존 계약](GUIDED_WORKFLOW.md)을 참고한다.

저장 후 또는 Measurement에서 산출 행을 선택하면 **저장된 산출과 원본 대조**가 표시된다. 원문·수동값, 확인 단위, 실제 계산 입력, 공제·면 수를 원본 이미지와 나란히 확인할 수 있다. 입력별 출처 보기로 해당 페이지를 선택하고, 자세한 측정은 원본을 크게 열어 수행한다. 저장 후 원본이나 계산 결과가 바뀌면 경고를 확인한다. 오래된 행에 입력 기록이 없으면 기록 없음으로 표시한다.

도면을 바꾸면 이전 도면의 검색·산출 결과를 지운다. 화면 사이를 이동해도 같은 탭에서 선택한 PDF는 유지된다. 확정 행은 명시적으로 DRAFT로 바꿔 재검토할 수 있다. 제외 행은 수정하거나 복구할 수 없다.

## 텍스트 추출이 안 될 때

도면 상세에서 Dimension region 모드를 선택하고 두 점으로 필요한 영역을 지정한다. 영역 미리보기를 확인하고 기존 추출의 문제를 기록한다. 외부 전송 권한과 기밀 여부를 확인한 경우에만 선택 영역을 판독한다. 전체 페이지를 한 번에 보내지 않으며, 판독 결과도 검수 후보로 남는다.

이미지 판독과 AI 검색은 서버 모델 설정이 필요하다. 설정 전에는 로컬 검색·수동 측정·계산·Excel을 사용할 수 있다. 설정은 [실행 명령](COMMANDS.md)을 따른다. API 키를 채팅·브라우저·Git에 적지 않는다.

## 검증한 것과 남은 것

- 합성 PDF의 두 기준 사례, 누락·단위 불명·다중 시트·확정 보호, 선택 영역 전송 계약을 자동 검증했다.
- 기존 비공개 PDF 130페이지를 별도 임시 DB에서 처리했다. 제공된 예제 입력 두 건으로 API와 브라우저에서 DRAFT 저장·Excel 출력을 확인했다. 원본 샘플과 기존 업무 DB는 수정하지 않았다.
- 이것은 실제 도면에서의 앱 동작 확인이다. 공제·면 수·현장 적용 기준을 실무자가 확정한 검증이나 AI 모델 품질 검증은 아니다.
- 사용자 제공 설정으로 실제 모델의 합성 검색·이미지 판독 E-01~E-06/V-01~V-03 최신 9항목이 통과했다. 일부 항목은 모델 호출 이후 서버 입력 검증 계약을 확인하며 모델 자체의 도면 이해 정확도를 측정한 결과는 아니다. 실무자의 최종 검수와 수동 대비 전체 작업시간 비교는 남아 있다. 실사용 비교 기록 화면의 시간 시작/종료와 관찰 기록을 사용하면 된다. 기록은 사용자 관찰값으로 구분한다.
- 외부 `.env`를 복사하지 않는 실행 명령과 합성 실제 호출 평가 명령은 `COMMANDS.md`에 있다. 정답 산출표가 없다면 실제 정확도는 미검증 상태로 유지한다.

상세 근거는 `AI_ASSIST_PROGRESS.md`, 사례별 자동 평가 범위는 `AI_ASSIST_EVALUATION.md`, PRD 요구사항별 상태는 `AI_ASSIST_AUDIT.md`에 정리했다.
