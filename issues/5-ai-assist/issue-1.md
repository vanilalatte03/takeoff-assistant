# 실모델 설정과 실무 검수 대기

## 현재 상태

기능 구현·자동 회귀 254개·웹 빌드·개발자 브라우저 검증은 통과했다. 비공개 130페이지 PDF의 제공 예제 두 건도 별도 임시 DB에서 계산 초안과 Excel까지 재현했다. 원본 업무 자료는 외부 전송하지 않았다.

검색 모델과 Vision 모델을 실제 호출하려면 서버의 TAKEOFF_AI_API_KEY, TAKEOFF_AI_MODEL, TAKEOFF_AI_VISION_MODEL이 필요하다. 연속된 세 작업 차례에서 설정 누락을 확인했으며, 최종 GET /assist/config는 ai_available=false, vision_available=false였다. 대체 응답 테스트를 실제 모델 품질·비용 검증으로 간주하지 않는다.

private 데이터셋의 형식 검증은 통과했지만 검수 필요 상태의 시작용 행을 실무자가 승인한 정답으로 간주하지 않는다. 현장 공제·면 수·최종 Excel 채택과 수동/보조 작업시간은 실무자가 확인해야 한다.

## 재개 조건

1. API 키를 채팅이나 Git에 적지 않고 서버 환경변수로 설정한다. 계정에서 사용할 수 있는 검색 모델과 이미지 입력 모델을 지정한다.
2. 로컬 앱을 재시작하고 두 모델의 사용 가능 여부를 확인한다.
3. 기밀 전송 권한을 확인한 자료 또는 합성 자료로 E-01~E-06과 선택 영역 판독을 실제 호출해 평가한다.
4. 실무자가 정답·공제·면 수를 승인하고 동일 과제의 수동/보조 비교 기록을 남긴다.

전체 목표를 완료 처리하지 않았으며, phase의 해당 gate는 blocked로 남긴다. 사용법은 docs/AI_ASSIST_HANDOFF.md, 요구사항별 판단은 docs/AI_ASSIST_AUDIT.md를 참조한다.


## 후속 상태 (2026-11-05)

사용자가 제공한 외부 설정으로 실제 모델 합성 평가 7항목이 통과했다. 키·모델 설정 차단은 해소됐다. 키와 원본 설정 파일은 수정하거나 복사하지 않았다. 정답 산출표 부재와 실무자 검수·현장 비교, 실제 도면의 외부 전송 가능 여부는 여전히 확인이 필요하다. 현재 결과와 실행 방법은 docs/AI_ASSIST_LIVE_RESULT.json 및 docs/COMMANDS.md를 따른다.
