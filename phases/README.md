# Phase 작업 안내

전체 목록은 [index.json](index.json), 제품 방향은 [PRD](../docs/PRD.md), 실행·검사는 [COMMANDS](../docs/COMMANDS.md)를 따른다.

현재 후속 작업은 [6차 사용성·평가](6-usability-evaluation/README.md)다. 이전 [5차 AI 보조](5-ai-assist/index.json)의 실무 검증은 완료되지 않았으며, 6차에서 평가 도구를 만든 사실만으로 해제하지 않는다.

- 한 단계는 최신 main에서 시작한 브랜치 하나와 PR 하나로 처리한다.
- 현재 step과 해당 step이 요구한 문서를 읽고 인수 기준을 검증한다. 다른 step의 범위를 함께 구현하지 않는다.
- 기능 변경에는 관련 회귀 테스트와 문서를 포함한다. 합성/대체 응답/실모델/실무 검증을 구분한다.
- 외부 Codex 읽기 전용 리뷰, 필수 CI와 로컬 검증을 통과한 뒤에만 머지한다. 리뷰 지적은 같은 PR에서 수정한다.
- index의 completed는 해당 step의 계약 충족을 뜻한다. PR 본문에 검증·외부 리뷰를 기록하고, 머지 후 GitHub 상태를 다시 확인한다.
- pending 중 의존성이 완료된 가장 이른 step을 선택한다. 실제 실무 게이트 때문에 막힌 step은 blocked로 남긴다.
- 개인 도면·산출표·DB·환경파일을 PR에 추가하지 않는다. 원래 작업 폴더에 남은 변경은 검토·보존 없이 덮어쓰거나 삭제하지 않는다.
